
# Objectif

Faire en en sorte que le Character Controller permette de:
- [ ] Se déplacer
- [ ] Sauter

Tout en ayant un maximum de paramètres customisables comme:
- [ ] Inputs
- [ ] Vitesse de marche
- [ ] Force du saut
- [ ] Jump
